# Publish PenSol on GitHub Pages

## Recommended repository name

```text
pensol
```

Your Pages URL will normally become:

```text
https://<github-username>.github.io/pensol/
```

## Publish

1. Create a new GitHub repository.
2. Upload or push the **contents** of the `pensol` folder into the repository root.
3. Commit to `main`.
4. Open **Settings** in the GitHub repository.
5. Select **Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose branch `main` and folder `/ (root)`.
8. Save.
9. Open the generated Pages URL once deployment completes.

## Before presenting publicly

Check these five items:

- Dashboard opens with 1,000 sample members.
- DB liability is approximately ₹694.83 crore under the default basis.
- Validation shows **Matched**.
- A member drill-down opens correctly.
- Sensitivities populate.

## Optional custom domain

A custom domain can be attached later in GitHub Pages settings. Do this only after the base Pages deployment is working.
