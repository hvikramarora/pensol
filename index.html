Privacy by architecture

Your uploaded census stays in the browser.

This static demo has no backend. Uploaded CSV data is parsed and valued locally in JavaScript; the application does not transmit member data to a server.

For a production implementation, security, authentication, encryption, data retention and access-control requirements would need to be designed explicitly.

  4. Stress key assumptions through one reusable engine.

Valuation methodology

Active members

Salary is projected to normal retirement age. Pensionable service is projected subject to the maximum service limit. The projected annual pension is the projected salary × projected service × accrual rate. The retirement pension is multiplied by survival to retirement, an increasing life-annuity factor, a simplified dependant-benefit loading and a discount factor back to the valuation date.

Deferred members

The accrued pension is based on salary at exit, accrued service and the accrual rate. It is increased to retirement using the deferment increase assumption, then valued using the same survival, annuity, dependant and discount framework.

Pensioners

The current annual pension is valued using an increasing life-annuity factor at current age plus the simplified dependant-benefit loading.

Why this is an Actuarial Engineering demo

The actuarial logic is a pure calculation layer. Data ingestion, validation, assumptions, calculations, reporting and UI are separate concerns. That makes the model easier to test, review, reuse and deploy beyond a single spreadsheet interface.
